9.2 Methods, __str__ and Class Attributes

Read: Python Unlocked, Chapter 8, "Methods" and "Class Attributes vs Instance Attributes"

Methods: functions that belong to a class

class Student:
    def __init__(self, name, gpa):
        self.name = name
        self.gpa = gpa
        self.courses = []            # every student starts with no courses

    def enroll(self, course_name):
        self.courses.append(course_name)
        print(f"{self.name} enrolled in {course_name}.")

    def is_honor_student(self):
        return self.gpa >= 3.75

student1 = Student("Priya Sharma", 3.85)
student1.enroll("Python Programming")
student1.enroll("Cloud Computing")
print(student1.courses)
print(student1.is_honor_student())

Every method's first parameter is self, but you don't pass it when calling. Python fills it in: student1.enroll("Python").

__str__: a readable printout

Printing an object normally shows something unhelpful like <__main__.Student object at 0x7f...>. Define __str__ to control what print() shows:

class Student:
    def __init__(self, name, gpa):
        self.name = name
        self.gpa = gpa

    def __str__(self):
        return f"Student: {self.name} | GPA: {self.gpa}"

print(Student("Priya Sharma", 3.85))

Methods with double underscores, like __init__ and __str__, are called magic methods (or "dunder" methods). Python calls them for you at special moments.

Class attributes vs instance attributes

An instance attribute (self.name) is different for each object. A class attribute is shared by all objects:

class Student:
    school_name = "CNM"          # class attribute: shared
    total_students = 0

    def __init__(self, name):
        self.name = name             # instance attribute: one per object
        Student.total_students += 1

s1 = Student("Priya")
s2 = Student("Rahul")
print(s1.school_name, s2.school_name)
print(f"Total students: {Student.total_students}")

Putting it together: a bank account

class BankAccount:
    def __init__(self, holder, balance=0):
        self.holder = holder
        self.balance = balance
        self.transactions = []

    def deposit(self, amount):
        if amount <= 0:
            print("Deposit must be greater than zero.")
            return
        self.balance += amount
        self.transactions.append(f"Deposit: ${amount:.2f}")

    def withdraw(self, amount):
        if amount > self.balance:
            print("Insufficient funds!")
            return
        self.balance -= amount
        self.transactions.append(f"Withdrawal: ${amount:.2f}")

    def __str__(self):
        return f"{self.holder}: ${self.balance:.2f}"

account = BankAccount("Maria Garcia", 100)
account.deposit(250)
account.withdraw(500)
account.withdraw(75)
print(account)
print(account.transactions)
