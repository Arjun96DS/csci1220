9.3 Inheritance

Read: Python Unlocked, Chapter 8, "Inheritance"

Inheritance lets you create a new class based on an existing one. The new child class gets everything from the parent class, and can add or change things.

class Student:
    def __init__(self, name, gpa):
        self.name = name
        self.gpa = gpa

    def introduce(self):
        print(f"Hi, I am {self.name}.")

    def __str__(self):
        return f"Student: {self.name} | GPA: {self.gpa}"


class GraduateStudent(Student):          # GraduateStudent inherits from Student
    def __init__(self, name, gpa, thesis_topic):
        super().__init__(name, gpa)      # let the parent set name and gpa
        self.thesis_topic = thesis_topic # then add what's new

    def introduce(self):                 # override (replace) the parent's version
        super().introduce()
        print(f"My thesis is on {self.thesis_topic}.")


grad = GraduateStudent("Sneha Patel", 3.91, "Cloud Security")
grad.introduce()
print(grad)          # __str__ was inherited from Student

Key ideas

  • class GraduateStudent(Student): means "a GraduateStudent is a Student."
  • super().__init__(...) runs the parent's constructor so you don't repeat that code (DRY).
  • Overriding: if the child defines a method with the same name, the child's version is used.
  • Methods the child doesn't define (like __str__ here) come from the parent automatically.

Checking an object's type

class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def speak(self):
        return "Woof!"

pets = [Dog("Rex"), Animal("Generic")]
for pet in pets:
    if isinstance(pet, Dog):
        print(f"{pet.name} says {pet.speak()}")
    else:
        print(f"{pet.name} is quiet.")
