Module 9 – Object-Oriented Programming

Large programs are built from objects: a bank account, a student, a smart light, each with its own data and actions. In this module you'll design your own classes, create objects from them, and use inheritance to build specialized versions without repeating code.

Reading: Python Unlocked, Chapter 8

By the end of this module, you will be able to:

  • 9.1 Explain classes, objects, encapsulation, and the DRY principle
  • 9.2 Define a class with an __init__ method and attributes
  • 9.3 Write methods and use the self parameter
  • 9.4 Use the __str__ magic method and class attributes
  • 9.5 Create child classes with inheritance, super(), and method overriding
