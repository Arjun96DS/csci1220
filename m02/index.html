Module 2 – Control Flow

Programs become useful when they can make decisions and repeat work. In this module you'll use if, elif, and else to make decisions, and for and while loops to repeat tasks.

Reading: Python Unlocked, Chapter 4

By the end of this module, you will be able to:

  • 2.1 Write if, elif, and else statements
  • 2.2 Combine conditions and nest if statements
  • 2.3 Repeat code with for loops and range()
  • 2.4 Repeat code with while loops
  • 2.5 Control loops with break and continue
  • 2.6 Validate user input with a while loop
