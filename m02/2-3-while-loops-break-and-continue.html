2.3 while Loops, break and continue

Read: Python Unlocked, Chapter 4, "while Loops" and "break and continue"

A while loop keeps running as long as its condition is True. Use it when you don't know in advance how many times to repeat, such as "keep asking until the user gets it right."

count = 1
while count <= 5:
    print(f"Count is currently: {count}")
    count += 1

If the condition never becomes False, the loop runs forever (an infinite loop). Here, forgetting count += 1 would do that. In Colab, click the stop button next to the cell to break out.

Example: a guessing game

secret_number = 7
guess = 0
while guess != secret_number:
    guess = int(input("Guess the secret number between 1 and 10: "))
    if guess == secret_number:
        print("You got it! Well done!")
    elif guess < secret_number:
        print("Too low! Try again.")
    else:
        print("Too high! Try again.")

break: stop the loop early

transactions = [450, 230, 1200, 89, 3400, 670, 150]
threshold = 1000
for amount in transactions:
    if amount > threshold:
        print(f"First large transaction found: ${amount}")
        break

continue: skip to the next item

scores = [85, 92, -1, 78, -1, 95, 60, -1, 88]
total = 0
valid_count = 0
for score in scores:
    if score == -1:
        print("Missing score found - skipping.")
        continue
    total += score
    valid_count += 1
print(f"Valid scores processed: {valid_count}")
print(f"Average score: {total / valid_count:.2f}")

{total / valid_count:.2f} shows the number with 2 decimal places.

The while True / break pattern (input validation)

A very common real-world pattern: keep asking until the input is valid.

while True:
    age = input("Please enter your age: ")
    if age.isdigit():
        age = int(age)
        print(f"Thank you! You are {age} years old.")
        break
    else:
        print("That does not look like a valid age. Please enter numbers only.")
