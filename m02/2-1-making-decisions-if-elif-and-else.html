2.1 Making Decisions – if, elif and else

Read: Python Unlocked, Chapter 4, "if, elif, and else" and "Nested if Statements"

So far, your programs run every line from top to bottom. Real programs need to make decisions: show a different message, charge a different price, or deny access. That is what if statements do.

The if statement

age = 20
if age >= 18:
    print("You are old enough to vote.")

Two rules beginners miss:

  • The if line ends with a colon :
  • The code that belongs to the if is indented (4 spaces). Python uses indentation, not brackets, to know which lines are inside the if.

if ... else

else runs when the condition is False:

age = 15
if age >= 18:
    print("You are old enough to vote.")
else:
    print("Sorry, you are not old enough to vote yet.")

elif: checking several options

Python checks each condition from the top and runs only the first one that is True:

score = 75
if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
elif score >= 60:
    print("Grade: D")
else:
    print("Grade: F")

Order matters. If you checked score >= 60 first, a score of 95 would get a D, because Python stops at the first match.

Combining conditions

Use and / or from Module 1 inside an if:

username = input("Enter your username: ")
password = input("Enter your password: ")
if username == "admin" and password == "python123":
    print("Login successful. Welcome back, Admin!")
elif username == "admin" and password != "python123":
    print("Wrong password. Please try again.")
else:
    print("Username not recognized.")

Nested if statements

You can put an if inside another if. Each level is indented further:

is_member = True
account_balance = 250
if is_member:
    if account_balance >= 500:
        print("You qualify for our premium rewards program.")
    elif account_balance >= 200:
        print("You qualify for our standard rewards program.")
    else:
        print("Add more funds to qualify for rewards.")
else:
    print("Please create a membership account first.")

Common mistakes: forgetting the colon, inconsistent indentation (IndentationError), and writing = (store) instead of == (compare).
