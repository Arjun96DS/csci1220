2.2 for Loops and range

Read: Python Unlocked, Chapter 4, "for Loops"

A loop repeats a block of code. A for loop goes through a collection of items one at a time.

Looping through a list

students = ["Priya", "Rahul", "Sneha", "Vikram", "Ananya"]
for student in students:
    print(f"Hello {student}, welcome to class!")

Each time through the loop, the variable student holds the next name. The indented line runs once per name.

Adding things up (the accumulator pattern)

Start a total at 0, then add to it inside the loop. You will use this pattern constantly:

prices = [299, 149, 899, 49, 599]
total = 0
for price in prices:
    total += price
print(f"Total cost: {total}")

Counting with range()

CodeProducesNotes
range(5)0, 1, 2, 3, 4Starts at 0, stops before 5
range(1, 6)1, 2, 3, 4, 5Start, stop (stop is not included)
range(0, 20, 5)0, 5, 10, 15Third number is the step
range(10, 0, -1)10, 9, ... 1Negative step counts down
for number in range(1, 6):
    print(number)

for i in range(10, 0, -1):
    print(i)
print("Liftoff!")

Putting it together: a multiplication table

number = 7
for i in range(1, 11):
    print(f"{number} x {i} = {number * i}")
