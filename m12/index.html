Module 12 – Databases with SQLite

Behind almost every app is a database. In this module you'll learn SQL, the language of databases and one of the most in-demand skills in IT, and use Python's built-in SQLite to create, read, update, and delete records safely.

Reading: The pages in this module (databases are not covered in Python Unlocked)

By the end of this module, you will be able to:

  • 12.1 Explain what a relational database, SQL, and SQLite are
  • 12.2 Connect to a database and create a table
  • 12.3 Insert data safely using ? placeholders
  • 12.4 Retrieve, filter, sort, and summarize data with SELECT
  • 12.5 Update and delete records
  • 12.6 Organize database code with functions and classes
