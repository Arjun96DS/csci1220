12.3 Updating, Deleting and Organizing Database Code

This module isn't covered in Python Unlocked. These pages are your reading.

Updating and deleting

import sqlite3
conn = sqlite3.connect("school.db")
cur = conn.cursor()

cur.execute("UPDATE students SET gpa = ? WHERE name = ?", (3.55, "Rahul"))
print(f"Updated {cur.rowcount} row(s)")

cur.execute("DELETE FROM students WHERE name = ?", ("Vikram",))
print(f"Deleted {cur.rowcount} row(s)")
conn.commit()
conn.close()

An UPDATE or DELETE without a WHERE clause changes or deletes every row in the table. Always double-check your WHERE.

cur.rowcount tells you how many rows were affected. If it's 0, nothing matched, which is useful for telling the user "not found".

Grouping: summary reports

import sqlite3
conn = sqlite3.connect("school.db")
cur = conn.cursor()
cur.execute("SELECT major, COUNT(*), ROUND(AVG(gpa), 2) FROM students GROUP BY major")
for major, count, avg in cur.fetchall():
    print(f"{major}: {count} student(s), average GPA {avg}")
conn.close()

Organizing database code with functions

Real programs wrap each database action in a function, and catch database errors with try/except:

import sqlite3

DB = "school.db"

def add_student(name, major, gpa):
    with sqlite3.connect(DB) as conn:        # commits automatically if no error
        conn.execute("INSERT INTO students (name, major, gpa) VALUES (?, ?, ?)", (name, major, gpa))

def find_by_major(major):
    with sqlite3.connect(DB) as conn:
        return conn.execute("SELECT name, gpa FROM students WHERE major = ?", (major,)).fetchall()

add_student("Ananya", "Cloud Computing", 3.70)
print(find_by_major("Cloud Computing"))

Using a class to hold the data

You can turn each row into an object (Module 9) so the rest of your program works with clean objects instead of tuples:

import sqlite3

class Student:
    def __init__(self, id, name, major, gpa):
        self.id, self.name, self.major, self.gpa = id, name, major, gpa

    def __str__(self):
        return f"#{self.id} {self.name} ({self.major}) GPA {self.gpa:.2f}"

with sqlite3.connect("school.db") as conn:
    rows = conn.execute("SELECT id, name, major, gpa FROM students").fetchall()
students = [Student(*row) for row in rows]     # * unpacks the tuple into arguments
for s in students:
    print(s)
