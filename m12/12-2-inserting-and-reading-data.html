12.2 Inserting and Reading Data

This module isn't covered in Python Unlocked. These pages are your reading.

Inserting data: always use ? placeholders

import sqlite3
conn = sqlite3.connect("school.db")
cur = conn.cursor()
cur.execute("CREATE TABLE IF NOT EXISTS students (id INTEGER PRIMARY KEY, name TEXT NOT NULL, major TEXT, gpa REAL)")
cur.execute("DELETE FROM students")      # start fresh for this example

cur.execute("INSERT INTO students (name, major, gpa) VALUES (?, ?, ?)",
            ("Priya", "Computer Science", 3.85))

more = [("Rahul", "Cybersecurity", 3.42), ("Sneha", "Cloud Computing", 3.91), ("Vikram", "Cybersecurity", 3.10)]
cur.executemany("INSERT INTO students (name, major, gpa) VALUES (?, ?, ?)", more)
conn.commit()
print(f"{cur.rowcount} rows inserted by executemany")
conn.close()

Never build SQL by gluing strings together, like f"... WHERE name = '{name}'". A user could type SQL code into your input and delete or steal your data. This is called SQL injection, and it's one of the most common security holes in real websites. The ? placeholders make input safe.

Reading data: SELECT

import sqlite3
conn = sqlite3.connect("school.db")
cur = conn.cursor()

cur.execute("SELECT name, major, gpa FROM students ORDER BY gpa DESC")
rows = cur.fetchall()            # a list of tuples
for name, major, gpa in rows:
    print(f"{name:<8}{major:<18}{gpa:.2f}")

cur.execute("SELECT name FROM students WHERE major = ?", ("Cybersecurity",))
print([row[0] for row in cur.fetchall()])

cur.execute("SELECT COUNT(*), AVG(gpa) FROM students")
count, avg = cur.fetchone()      # just one row
print(f"{count} students, average GPA {avg:.2f}")
conn.close()
SQLMeaning
SELECT name, gpa FROM studentsget these columns from this table
WHERE gpa >= 3.5only rows that match
ORDER BY gpa DESCsort, highest first
COUNT(*), AVG(gpa), SUM()summary calculations
fetchall() / fetchone()(Python) get all rows / one row

Notice the trailing comma in ("Cybersecurity",). Placeholder values must be a tuple, even when there's only one (remember Module 4).
