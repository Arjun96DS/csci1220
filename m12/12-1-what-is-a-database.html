12.1 What Is a Database

This module isn't covered in Python Unlocked. These pages are your reading.

Files are fine for small amounts of data. Real applications (banking, shopping, school records) use a database, which can store millions of records and find any of them instantly.

Key ideas

  • A relational database stores data in tables, like spreadsheets: each row is a record and each column is a field.
  • SQL (Structured Query Language) is the language used to talk to databases. It's one of the most in-demand skills in IT and data jobs.
  • SQLite is a small database that lives in a single file. Python includes it (sqlite3), so there's nothing to install, and it works in Google Colab.

The basic process

  1. Connect to the database file (it's created if it doesn't exist).
  2. Get a cursor, the object that runs SQL commands.
  3. Execute SQL.
  4. Commit to save changes.
  5. Close the connection.
import sqlite3

conn = sqlite3.connect("school.db")       # 1. connect (creates school.db)
cur = conn.cursor()                        # 2. cursor

cur.execute("""
    CREATE TABLE IF NOT EXISTS students (
        id INTEGER PRIMARY KEY,
        name TEXT NOT NULL,
        major TEXT,
        gpa REAL
    )
""")                                       # 3. execute SQL
conn.commit()                              # 4. save
conn.close()                               # 5. close
print("Database and table ready.")

Reading the CREATE TABLE command

  • IF NOT EXISTS: only create the table the first time
  • INTEGER PRIMARY KEY: a unique ID number SQLite fills in automatically
  • TEXT, INTEGER, REAL: the column types (string, int, float)
  • NOT NULL: this column can't be left empty

SQL keywords are written in CAPITALS by convention so they stand out from table and column names. SQL itself doesn't care about case.
