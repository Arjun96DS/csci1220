10.2 The datetime Module

Read: Python Unlocked, Chapter 9, "The datetime Module"

Dates and times are everywhere: due dates, timestamps, ages, subscriptions. The datetime module handles them correctly (leap years, month lengths, and so on).

from datetime import datetime, date, timedelta

now = datetime.now()
today = date.today()
print(now)
print(today)
print(now.year, now.month, now.day, now.hour)

Creating specific dates

from datetime import date, datetime
graduation = date(2027, 5, 14)
meeting = datetime(2026, 11, 3, 9, 30)
print(graduation, meeting)

Formatting dates with strftime

from datetime import datetime
moment = datetime(2026, 11, 3, 14, 5)
print(moment.strftime("%m/%d/%Y"))          # 11/03/2026 (US format)
print(moment.strftime("%B %d, %Y"))         # November 03, 2026
print(moment.strftime("%A at %I:%M %p"))    # Tuesday at 02:05 PM
CodeMeaningExample
%Y4-digit year2026
%mmonth number11
%dday03
%Bmonth nameNovember
%Aweekday nameTuesday
%I:%M %p12-hour time02:05 PM
%H:%M24-hour time14:05

Reading dates from text with strptime

from datetime import datetime
text = "11/03/2026"
d = datetime.strptime(text, "%m/%d/%Y")
print(d.strftime("%A"))      # Tuesday

Date math with timedelta

from datetime import date, timedelta
today = date(2026, 11, 3)
print(today + timedelta(days=30))             # 30 days from now
print(today - timedelta(weeks=2))             # 2 weeks ago
deadline = date(2026, 12, 12)
print(f"{(deadline - today).days} days until the deadline")

Store dates in files as YYYY-MM-DD text (date.isoformat()). It sorts correctly and converts back easily with date.fromisoformat().
