Module 10 – Useful Python Libraries

You don't have to build everything yourself. Python's standard library gives you ready-made tools for math, randomness, dates, files and folders, and JSON, the data format behind almost every web app. In this module you'll put those "batteries" to work.

Reading: Python Unlocked, Chapter 9

By the end of this module, you will be able to:

  • 10.1 Import modules in different ways
  • 10.2 Use the math and random modules
  • 10.3 Create, format, parse, and calculate with dates using datetime
  • 10.4 Work with files and folders using os
  • 10.5 Save and load structured data with json
