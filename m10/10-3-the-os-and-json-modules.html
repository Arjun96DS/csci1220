10.3 The os and json Modules

Read: Python Unlocked, Chapter 9, "The os Module" and "The json Module"

The os module: working with files and folders

import os
print(os.getcwd())                          # current folder
os.makedirs("reports", exist_ok=True)       # create a folder (no error if it exists)
path = os.path.join("reports", "november.txt")   # builds a correct path on any OS
print(path)
print(os.path.exists(path))                 # does the file exist?
print(os.listdir("."))                      # what's in this folder?

os.path.exists() is the clean way to check for a file before opening it, an alternative to catching FileNotFoundError.

The json module: saving structured data

JSON is the format the web runs on: almost every API sends data as JSON. It looks almost exactly like Python dictionaries and lists, so it's perfect for saving them.

import json

student = {"name": "Priya Sharma", "gpa": 3.85, "courses": ["Python", "Cloud"]}

# Python -> JSON text
text = json.dumps(student, indent=4)
print(text)

# JSON text -> Python
data = json.loads('{"name": "Rahul", "gpa": 3.42}')
print(data["name"])

Saving and loading a JSON file

import json, os

settings = {"theme": "dark", "volume": 7, "favorites": ["jazz", "lofi"]}
with open("settings.json", "w") as f:
    json.dump(settings, f, indent=4)       # save

if os.path.exists("settings.json"):
    with open("settings.json", "r") as f:
        loaded = json.load(f)              # load
    print(loaded["favorites"])
