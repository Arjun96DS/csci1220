10.1 The math and random Modules

Read: Python Unlocked, Chapter 9, "The math Module" and "The random Module"

Python comes with a huge standard library, ready-made modules for math, dates, files, data formats, and more. People say Python comes with "batteries included". To use a module, import it at the top of your program.

Three ways to import

import math                     # use as math.sqrt()
from math import sqrt, pi       # use as sqrt() and pi directly
import datetime as dt           # give the module a short nickname
print(math.sqrt(144), sqrt(81), round(pi, 2))

The math module

import math
print(math.pi)              # 3.141592653589793
print(math.sqrt(144))       # 12.0
print(math.floor(4.7))      # 4  (round down)
print(math.ceil(4.2))       # 5  (round up)
print(math.pow(2, 10))      # 1024.0

Example: how many boxes do you need to ship 250 items if each box holds 24? You can't ship 10.4 boxes, so round up:

import math
print(math.ceil(250 / 24))   # 11 boxes

The random module

import random
print(random.randint(1, 6))                 # dice roll: 1 to 6
print(random.random())                      # float from 0.0 to 1.0
colors = ["red", "green", "blue"]
print(random.choice(colors))                # one random item
print(random.sample(range(1, 50), 6))       # 6 unique lottery numbers
random.shuffle(colors)                      # shuffle in place
print(colors)

Setting a seed makes "random" results repeatable, which is useful for testing:

import random
random.seed(42)
print(random.randint(1, 100), random.randint(1, 100))
random.seed(42)
print(random.randint(1, 100), random.randint(1, 100))   # same two numbers again

random is fine for games and simulations, but never use it for passwords or security tokens, because it's predictable. Use the secrets module instead (you'll see it in Module 11).
