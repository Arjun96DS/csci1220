5.3 Formatting Output with f-strings

Read: Python Unlocked, Chapter 3, "Print and Input" (f-strings)

Good output is part of good software. f-strings can control decimals, commas, and alignment so your reports look professional.

Number formatting

price = 1234.5
rate = 0.0725
print(f"Price: ${price:.2f}")       # 2 decimal places   -> $1234.50
print(f"Price: ${price:,.2f}")      # with comma         -> $1,234.50
print(f"Tax rate: {rate:.1%}")      # as a percentage    -> 7.2%
print(f"Order #{42:05d}")           # pad with zeros     -> 00042

Alignment: building tables

Inside { }, < means left-align, > means right-align, and the number is the column width:

items = [("Laptop", 899.99), ("Mouse", 24.5), ("USB-C Hub", 39)]
print(f"{'Item':<12}{'Price':>10}")
print("-" * 22)
for name, cost in items:
    print(f"{name:<12}{cost:>10.2f}")
Item             Price
----------------------
Laptop          899.99
Mouse            24.50
USB-C Hub        39.00

Old-style formatting you may see online

Older code uses % or .format(). You don't need to write these, but you should recognize them:

name, score = "Priya", 92.456
print("%s scored %.1f" % (name, score))          # old % style
print("{} scored {:.1f}".format(name, score))    # .format() style
print(f"{name} scored {score:.1f}")              # f-string (use this one)

Practice

  1. Ask for a full name and print it as "Last, First" in title case, no matter how the user typed it.
  2. Ask for an email address and check it has exactly one @ and ends with .com, .edu, or .org.
  3. Print a receipt for three items with names left-aligned and prices right-aligned, with a total at the bottom.
