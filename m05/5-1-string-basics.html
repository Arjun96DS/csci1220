5.1 String Basics

Read: Python Unlocked, Chapter 3, "Strings" (review)

Almost every program works with text: names, emails, file names, log messages, web data. In Python, text is a string (str). This module goes deeper than Module 1.

Strings are sequences

A string is an ordered sequence of characters, so indexing and slicing work exactly like lists:

word = "Albuquerque"
print(word[0])      # A
print(word[-1])     # e
print(word[0:4])    # Albu
print(word[::-1])   # euqreuqublA
print(len(word))    # 11

Strings are immutable

You can't change a single character of a string. You build a new string instead:

name = "python"
# name[0] = "P"           # TypeError: strings can't be changed
name = "P" + name[1:]     # build a new string instead
print(name)               # Python

Joining and repeating

first = "Ada"
last = "Lovelace"
print(first + " " + last)   # concatenation
print("-" * 30)             # repetition: a line of 30 dashes
print("ha" * 3)             # hahaha

Looping through characters

password = "Sunset#River42"
digits = 0
for ch in password:
    if ch.isdigit():
        digits += 1
print(f"{password} contains {digits} digits")
