Module 5 – Working with Strings

Text is everywhere: names, emails, file paths, log files, web data. In this module you'll learn to search, clean, split, and format strings, the same skills IT and data professionals use to make sense of messy real-world text.

Reading: Python Unlocked, Chapter 3 (Strings and f-strings review) plus the pages in this module

By the end of this module, you will be able to:

  • 5.1 Index, slice, and loop through strings
  • 5.2 Explain why strings are immutable
  • 5.3 Clean and search text with strip, lower, upper, find, count, and replace
  • 5.4 Break text apart with split() and combine it with join()
  • 5.5 Format numbers and align output with f-strings
