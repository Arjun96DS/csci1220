5.2 String Methods

Reference: the full list is in the Python documentation for string methods.

String methods are built-in tools for cleaning, searching, and reshaping text. Because strings are immutable, every method returns a new string. It doesn't change the original.

Cleaning text

raw = "   MGarcia@CNM.edu   "
clean = raw.strip().lower()     # remove outer spaces, then lowercase
print(f"[{raw}] -> [{clean}]")
print("hello world".title())    # Hello World
print("hello".upper())          # HELLO

Always clean user input before comparing it. answer.strip().lower() == "yes" accepts "Yes", " YES ", and "yes".

Searching: find() and count()

email = "mgarcia@cnm.edu"
at = email.find("@")            # position of @, or -1 if not found
print(at)                        # 7
username = email[:at]            # everything before @
domain = email[at + 1:]          # everything after @
print(username, domain)
print("banana".count("a"))       # 3
print(email.find("#"))           # -1 means not found

Replacing text

message = "Your order ships Monday. Monday delivery is guaranteed."
print(message.replace("Monday", "Tuesday"))
phone = "505-555-0142"
print(phone.replace("-", ""))    # 5055550142

split(): breaking a string into a list

This is one of the most useful methods. It's how programs read data files and logs.

sentence = "Python is fun to learn"
words = sentence.split()          # split on spaces
print(words)
print(len(words), "words")

record = "Maria,Garcia,Albuquerque,NM"
parts = record.split(",")         # split on commas
print(parts[0], parts[2])

line = "2026-10-30 08:16:10 ERROR auth-service Account locked"
date, time, level, rest = line.split(" ", 3)   # split at most 3 times
print(level, "|", rest)

join(): turning a list back into a string

tags = ["python", "beginner", "cnm"]
print(", ".join(tags))       # python, beginner, cnm
print("-".join(["2026", "10", "31"]))
