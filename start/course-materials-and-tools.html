Course Materials and Tools

Textbook: Python Unlocked: From Zero to Machine Learning

By Arjun Sunke and Sriharsha Gudi. Chapters 1–9 cover this course; the chapter PDFs are in each Brightspace module. Chapters 10–16 (NumPy, Pandas, data visualization and machine learning) are covered in Python II.

Code: Google Colab notebooks

Every code example from the book is in a ready-to-run notebook. Each module links to its chapter's notebook.

  • You need a free Google account (a Gmail account works).
  • Colab runs in your web browser, so it works on any computer, including Chromebooks.
  • To keep your changes, use File → Save a copy in Drive.
  • All notebooks are also on GitHub: github.com/Arjun96DS/python-unlocked

Python on your own computer

Colab is enough for Modules 1–10 and 12. For Module 11 (GUIs) you'll need Python and VS Code on your computer. Page 1.2 shows you how.

GitHub

You'll turn in your work through GitHub. See Submitting Your Work with GitHub.

What you'll need

  • A computer with a modern web browser (Chrome, Edge, Firefox, or Safari)
  • A reliable internet connection
  • Free Google and GitHub accounts

These lessons stay available

This site stays online after the course ends, so you can come back to review before a job interview or a future class.
