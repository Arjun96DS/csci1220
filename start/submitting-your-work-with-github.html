Submitting Your Work with GitHub

In this course you turn in your programs through GitHub, the website professional developers use to store and share code. You'll keep all your work for the course in one place, and you'll finish with a portfolio of programs you can show an employer.

This page shows you how to do everything in your web browser, with nothing to install. In Module 11 you'll learn to do the same thing from your own computer.

Words you'll see

WordMeaning
Repository (repo)A project folder on GitHub. You'll have one repo for this whole course.
CommitA saved snapshot of your files, with a short message describing what changed. GitHub keeps every commit, so nothing you save is ever lost.
CollaboratorSomeone you give access to your private repo, such as your instructor.

Step 1: Create a free GitHub account

Go to github.com/signup. Choose a professional username, because employers may see it later. As a student you can also apply for the free GitHub Student Developer Pack.

Step 2: Create your course repo (once)

  1. Click the + at the top right of GitHub → New repository.
  2. Repository name: csci1220-python
  3. Choose Private. Only you and the people you invite can see it.
  4. Tick Add a README file, then click Create repository.

Step 3: Give your instructor access (once)

  1. In your repo, click Settings → Collaborators → Add people.
  2. Type your instructor's GitHub username. You'll find it in Brightspace.
  3. Click Add to this repository. Your instructor accepts the invitation from their side.

Step 4: Add your work for a module

Keep each module in its own folder: module-01, module-02, and so on.

  1. In your repo, click Add file → Upload files.
  2. Drag in your files: your .py file or Colab notebook (File → Download → Download .ipynb), plus any screenshots the assignment asks for.
  3. To put them in a folder, drag in the whole folder, or first use Add file → Create new file and type module-01/README.md. The / creates the folder.
  4. Under Commit changes, write a short message that says what you did, for example Add Module 1 trip cost calculator.
  5. Click Commit changes.

Fixing something? Upload the corrected file again with the same name and a new commit message, such as Fix gallons calculation. GitHub keeps both versions, and your instructor can see what you changed.

Step 5: Submit the link in Brightspace

  1. On GitHub, open the module's folder, for example module-01.
  2. Copy the address from your browser's address bar. It looks like https://github.com/your-username/csci1220-python/tree/main/module-01.
  3. Paste that link into the module's assignment in Brightspace.

Your instructor grades the files in that folder as of your last commit before the due date.

Good habits

  • Commit when you finish each part, not only at the end. Several small commits show your progress.
  • Write commit messages that start with a verb: Add, Fix, Update.
  • Never upload passwords or personal information.

Stuck? Ask your instructor or classmates and include a screenshot. Everyone finds GitHub a little confusing the first time.
