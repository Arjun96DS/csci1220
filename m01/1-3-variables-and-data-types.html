1.3 Variables and Data Types

Read: Python Unlocked, Chapter 3 (Variables and Data Types)

What is a variable?

A variable is a named container that stores a value so you can use it later. You create one with the = sign:

name = "Arjun"
age = 30
height = 5.11
is_student = True
print(name)
print(age)
print(height)
print(is_student)

Read it as: "store "Arjun" in the variable name." The = means assign, not "equals" like in math.

Naming rules

  • Use letters, numbers, and underscores: first_name, score2
  • Can't start with a number: 2score ❌
  • No spaces: first name ❌
  • Names are case-sensitive: Age and age are different variables

The four basic data types

TypeWhat it storesExamples
str (string)Text, inside quotes"Hello", "Albuquerque"
int (integer)Whole numbers30, -5, 100
floatNumbers with a decimal point3.85, 72.5
bool (boolean)True or FalseTrue, False

Strings

Strings hold text. You can join them with +, count their characters with len(), and change their case:

first_name = "Arjun"
last_name = "Sunke"
greeting = "Hello, welcome to Python!"

full_name = first_name + " " + last_name
print(full_name)          # Arjun Sunke
print(len(greeting))      # 25
print(greeting.upper())   # HELLO, WELCOME TO PYTHON!
print(greeting.lower())   # hello, welcome to python!

Integers and floats

students = 30        # int
temperature = -5     # int
gpa = 3.85           # float
weight = 72.5        # float

You can convert between them:

x = 10
print(float(x))   # 10.0

z = 3.99
print(int(z))     # 3  (int() cuts off the decimal, it does NOT round)

Booleans

A boolean is either True or False (capital T and F). Comparisons produce booleans:

is_raining = True
print(is_raining)   # True
print(10 > 5)       # True
print(10 == 10)     # True
print(10 != 5)      # True

Checking a value's type

Not sure what type something is? Ask Python with type():

print(type("Hello"))   # <class 'str'>
print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type(True))      # <class 'bool'>

Check your understanding

  1. What data type is "42"? What about 42?
  2. What does int(9.99) give you?
  3. Which of these is a valid variable name: my score, my_score, 1score?
