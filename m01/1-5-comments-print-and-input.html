1.5 Comments, Print and Input

Read: Python Unlocked, Chapter 3 (Comments; Print and Input)

Comments

A comment starts with #. Python ignores it. Comments are notes for humans, explaining what your code does.

# This is a comment. Python will not run this line
print("But Python will run this line")

age = 25  # Storing the user's age

Get in the habit now: every program you submit in this course should have comments explaining what each part does.

print(): showing output

print() displays text, numbers, or variables on the screen:

print("Hello World")
print(42)
print(3.14)

name = "Arjun"
age = 30
city = "Albuquerque"
print(name, age, city)   # Arjun 30 Albuquerque

f-strings: the easy way to mix text and variables

Put an f before the quotes, then put variables inside { }:

print(f"My name is {name}, I am {age} years old and I live in {city}.")

You can even do math inside the braces:

price = 1200
discount = 0.10
print(f"Original price: {price}")
print(f"Discount amount: {price * discount}")
print(f"Final price: {price - (price * discount)}")

input(): getting information from the user

input() shows a question, waits for the user to type, and gives back what they typed:

user_name = input("What is your name? ")
print(f"Hello {user_name}, great to meet you!")

Important: input() always gives you a string, even if the user types a number. To do math with it, convert it first with int() or float().

user_age = input("How old are you? ")
user_age = int(user_age)          # convert text to a whole number
next_birthday = user_age + 1
print(f"On your next birthday you will be {next_birthday} years old.")

Practice (from Chapter 3)

  3. Create three booleans: is_employed, has_degree, has_experience. Use and, or, and not to print: Is the person employed and has a degree? Has a degree or experience? Not employed?
