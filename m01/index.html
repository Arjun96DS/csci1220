Module 1 – Getting Started & Python Basics

In this module you'll get Python running, write your first program, and learn the building blocks every program uses: variables, data types, operators, and input and output.

Reading: Python Unlocked, Chapters 1–3

By the end of this module, you will be able to:

  • 1.1 Explain what Python is and why it's widely used
  • 1.2 Set up a Python environment and run code
  • 1.3 Write and run your first Python script
  • 1.4 Create variables using strings, integers, floats, and booleans
  • 1.5 Check a value's data type
  • 1.6 Use arithmetic, comparison, logical, and assignment operators
  • 1.7 Write comments to explain code
  • 1.8 Get input from the user and display output
