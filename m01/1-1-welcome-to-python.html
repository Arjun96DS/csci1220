1.1 Welcome to Python

Read: Python Unlocked, Chapter 1

What is Python?

Python is a programming language: a way to give a computer step-by-step instructions. It was designed to be easy to read, so Python code looks a lot like plain English.

Why learn Python?

  • Beginner-friendly: fewer symbols and rules than most languages
  • Used everywhere: websites, automation, data analysis, cloud tools, and artificial intelligence
  • Free and open source: anyone can download and use it
  • Huge community: if you get stuck, someone has almost certainly answered your question online

See the difference

Printing one message in Python:

print("Hello, welcome to Python!")

The same thing in Java:

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, welcome to Java!");
    }
}

Python needs one line. That simplicity is why it's a great first language.

Try it now
