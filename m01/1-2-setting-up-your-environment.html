1.2 Setting Up Your Environment

Read: Python Unlocked, Chapter 2

Before we write real programs, we need a place to write and run Python code. In this course you have two options. Start with Option 1. Option 2 is optional for now.

Don't panic if setup doesn't work the first time. Even experienced developers spend time fixing their setups. If you get stuck, ask your instructor or classmates and include a screenshot.

Option 1: Google Colab (recommended, nothing to install)

Google Colab lets you write and run Python in your web browser. It works on any computer, including Chromebooks.

  1. Go to colab.research.google.com and sign in with a Google account (a free Gmail account works).
  2. Click New notebook.
  3. Click inside the empty cell and type:
print("Hello! My Python environment is working!")
  1. Press Shift + Enter to run the cell. You should see this output below it:
Hello! My Python environment is working!

That's your first Python output!

Notebook basics

  • Cell: the box where you type code. A notebook can have many cells, and you can run each one separately.
  • Shift + Enter: runs the current cell.
  • + Code: adds a new code cell.
  • Saving: when you open one of the book's notebooks, go to File → Save a copy in Drive so your changes are saved to your own Google Drive.

Option 2: Install Python on your computer (optional for now)

If you want Python on your own computer, Chapter 2 walks you through every step. Here's the short version:

  1. Install Anaconda from anaconda.com/download. It installs Python plus Jupyter Notebook in one go.
  2. Check that it worked. Open Anaconda Prompt (Windows) or Terminal (Mac) and type: 
    conda --version
    If you see a version number (like conda 23.7.4) and not an error, it worked.
  3. Launch Jupyter Notebook by typing: 
    jupyter notebook
    Your browser opens the Jupyter dashboard. Click New → Python 3 to create a notebook.
  4. Install VS Code from code.visualstudio.com, then install the Python extension by Microsoft from the Extensions panel.

You'll need Option 2 by Module 11 (GUIs), because GUI programs don't run in Colab. Installing early is a good idea.

Your first real Python script

In Colab (or VS Code), type this program exactly as shown and run it:

name = input("Hey there! What is your name? ")
age = input("Nice to meet you! How old are you? ")
print("So your name is " + name + " and you are " + age + " years old.")
print("Welcome to Python, " + name + "! This is going to be a great journey.")

Python will stop and wait for you to type your name, then your age. Then it prints a personal message.

What each line does

  • Line 1: input() pauses the program and waits for you to type. Whatever you type is stored in a variable called name. A variable is a container that holds information for later.
  • Line 2: Same idea. Your age is stored in the variable age.
  • Line 3: print() displays a message. The + joins pieces of text together. This is called concatenation.
  • Line 4: Prints a personalized welcome using the name variable.

Try it now

Open the Chapter 2 notebook in Google Colab and run each cell with Shift + Enter.

Practice

  1. Change the script so it also asks for your favorite food, then prints one sentence that includes your name, age, and favorite food.
  2. Write a new program that asks five different questions and prints all five answers together in one summary sentence at the end.
  3. In a new notebook, make the first cell print your full name and the second cell ask for your city using input(). Run both cells.
