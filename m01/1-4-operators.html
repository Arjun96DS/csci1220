1.4 Operators

Read: Python Unlocked, Chapter 3 (Operators)

Operators are symbols that tell Python to do something with values, like add them, compare them, or combine them.

Arithmetic operators

a = 15
b = 4
print(a + b)    # Addition        → 19
print(a - b)    # Subtraction     → 11
print(a * b)    # Multiplication  → 60
print(a / b)    # Division        → 3.75
print(a // b)   # Floor division  → 3  (whole number part only)
print(a % b)    # Modulus         → 3  (the remainder)
print(a ** b)   # Exponent        → 50625  (15 to the power of 4)

Tip: % (modulus) is handy for checking whether a number is even: if number % 2 is 0, the number is even.

Comparison operators

These compare two values and always give back True or False:

x = 10
y = 20
print(x == y)   # Equal to              → False
print(x != y)   # Not equal to          → True
print(x > y)    # Greater than          → False
print(x < y)    # Less than             → True
print(x >= y)   # Greater than or equal → False
print(x <= y)   # Less than or equal    → True

Common mistake: = stores a value. == compares two values.

Logical operators

These combine True/False conditions:

  • and: True only if both sides are True
  • or: True if at least one side is True
  • not: flips True to False and False to True
age = 25
has_id = True
print(age >= 18 and has_id)    # True
print(age >= 18 or has_id == False)   # True
print(not has_id)              # False

A real-world example:

temperature = 28
is_weekend = True
has_sunscreen = False
can_go_to_beach = temperature > 25 and is_weekend and has_sunscreen == False
print(can_go_to_beach)   # True

Assignment operators

These are shortcuts for updating a variable:

score = 100
score += 10    # same as score = score + 10  → 110
score -= 5     # same as score = score - 5   → 105
score *= 2     # same as score = score * 2   → 210
score //= 3    # same as score = score // 3  → 70
print(score)

Check your understanding

  1. What is 17 % 5? What is 17 // 5?
  2. What does True and False give you? What about True or False?
  3. If points = 50, what is points after points += 25?
