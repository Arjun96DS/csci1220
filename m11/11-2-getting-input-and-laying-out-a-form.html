11.2 Getting Input and Laying Out a Form

This module isn't covered in Python Unlocked. These pages are your reading.

Important: GUI programs open a window on your computer, so they do not run in Google Colab. For this module, use Python installed on your computer (Anaconda from Module 1 includes everything you need) and run your code in VS Code or IDLE. If you haven't installed Python yet, follow Option 2 on page 1.2.

Getting text from the user: Entry

import tkinter as tk

def greet():
    name = name_entry.get()           # read what the user typed
    result.config(text=f"Hello, {name}!")

window = tk.Tk()
window.title("Greeter")
tk.Label(window, text="Your name:").pack()
name_entry = tk.Entry(window, width=25)
name_entry.pack(pady=5)
tk.Button(window, text="Greet", command=greet).pack(pady=5)
result = tk.Label(window, text="")
result.pack(pady=5)
window.mainloop()

Like input(), entry.get() always returns a string.

Layout with grid()

pack() stacks widgets. grid() places them in rows and columns, which is better for forms:

import tkinter as tk

def calculate():
    bill = float(bill_entry.get())
    tip_pct = float(tip_entry.get())
    people = int(people_entry.get())
    total = bill * (1 + tip_pct / 100)
    result.config(text=f"Total: ${total:.2f}  |  Each: ${total / people:.2f}")

window = tk.Tk()
window.title("Tip Calculator")

tk.Label(window, text="Bill ($):").grid(row=0, column=0, sticky="e", padx=5, pady=5)
bill_entry = tk.Entry(window)
bill_entry.grid(row=0, column=1, padx=5)

tk.Label(window, text="Tip (%):").grid(row=1, column=0, sticky="e", padx=5, pady=5)
tip_entry = tk.Entry(window)
tip_entry.insert(0, "18")                       # default value
tip_entry.grid(row=1, column=1, padx=5)

tk.Label(window, text="People:").grid(row=2, column=0, sticky="e", padx=5, pady=5)
people_entry = tk.Entry(window)
people_entry.insert(0, "1")
people_entry.grid(row=2, column=1, padx=5)

tk.Button(window, text="Calculate", command=calculate).grid(row=3, column=0, columnspan=2, pady=10)
result = tk.Label(window, text="", font=("Arial", 12))
result.grid(row=4, column=0, columnspan=2, pady=5)

window.mainloop()
  • row and column start at 0.
  • sticky="e" aligns to the right (east) side of the cell.
  • columnspan=2 lets a widget stretch across two columns.
  • entry.insert(0, "18") puts a default value in the box.

Don't mix pack() and grid() in the same window. Pick one.
