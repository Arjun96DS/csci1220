Module 11 – Graphical User Interfaces

Most people never see a command line. They click buttons in windows. In this module you'll build desktop apps with windows, buttons, text boxes, and pop-ups using tkinter, which is built in to Python.

Reading: The pages in this module (GUIs are not covered in Python Unlocked)

By the end of this module, you will be able to:

  • 11.1 Compare common Python GUI frameworks
  • 11.2 Plan a GUI with a sketch
  • 11.3 Open a window and add labels and buttons
  • 11.4 Read user input from Entry widgets and lay out a form with grid()
  • 11.5 Use Checkbuttons, Spinbox, and messagebox
  • 11.6 Build a complete GUI application

Note: GUI programs don't run in Google Colab. You'll need Python installed on your computer for this module (see page 1.2, Option 2).
