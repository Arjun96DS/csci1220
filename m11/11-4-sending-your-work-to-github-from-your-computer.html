11.4 Sending Your Work to GitHub from Your Computer

Since Module 11 you have Python and VS Code on your computer. Now you can send your work to GitHub straight from VS Code instead of uploading files in the browser. This is how developers work every day.

Step 1: Install Git

  • Windows: download from git-scm.com/downloads and run the installer. The default options are fine.
  • Mac: open Terminal and type git --version. If Git isn't installed, your Mac offers to install it. Click Install.

Close and reopen VS Code afterward.

Step 2: Tell Git who you are (once)

In VS Code, open Terminal → New Terminal and run these two commands with your name and the email on your GitHub account:

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
  • user.name is the name shown on your commits.
  • user.email links your commits to your GitHub account.
  • --global means "use these settings for every project on this computer."

Step 3: Download your course repo (once)

  1. In VS Code, press Ctrl + Shift + P (Mac: Cmd + Shift + P), type Git: Clone, and press Enter.
  2. Choose Clone from GitHub. VS Code opens your browser so you can sign in. Click Authorize.
  3. Pick your csci1220-python repo, choose a folder (for example Documents), and click Open.

You now have a copy of your repo on your computer, with all your earlier modules in it.

Step 4: Save and send your work

Create your files for the module in a new folder, such as module-11. Then, in the VS Code terminal:

git status
git add module-11
git commit -m "Add Module 11 password generator"
git push
CommandWhat it does
git statusShows which files are new or changed since your last commit
git add module-11Chooses what goes into the next snapshot (here, the whole module-11 folder)
git commit -m "..."Saves the snapshot on your computer with a message
git pushUploads your commits to GitHub

Refresh your repo on GitHub: your folder and commit message are there. Submit the folder's link in Brightspace exactly as before.

Prefer buttons? VS Code's Source Control panel (the branch icon on the left) does the same thing: + stages a file, the message box and Commit button commit, and Sync Changes pushes.

Changed something on GitHub's website?

If you uploaded or edited files in the browser, bring those changes to your computer before you start working:

git pull
