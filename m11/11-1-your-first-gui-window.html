11.1 Your First GUI Window

This module isn't covered in Python Unlocked. These pages are your reading.

Important: GUI programs open a window on your computer, so they do not run in Google Colab. For this module, use Python installed on your computer (Anaconda from Module 1 includes everything you need) and run your code in VS Code or IDLE. If you haven't installed Python yet, follow Option 2 on page 1.2.

A GUI (graphical user interface) is a program with windows, buttons, and text boxes instead of typed commands. Python can build GUIs with several frameworks:

tkinterSimple desktop apps; perfect for learningBuilt in to Python

We'll use tkinter because it's built in and the concepts carry over to every other framework.

Plan before you code: sketch it

Professional developers sketch the screen first (on paper or with a tool like Figma). Draw boxes for each part of the window and label them: title text, input box, button, result area. Then build it piece by piece.

Your first window

import tkinter as tk

window = tk.Tk()                     # create the main window
window.title("My First App")         # text in the title bar
window.geometry("320x150")           # width x height in pixels

label = tk.Label(window, text="Hello, CNM!", font=("Arial", 18))
label.pack(pady=20)                  # place it in the window

window.mainloop()                    # keep the window open and listening

Line by line

  • tk.Tk() creates the window. Every tkinter app has exactly one.
  • Widgets are the pieces: Label (text), Button, Entry (text box), and more.
  • pack() places a widget in the window. pady adds space above and below.
  • mainloop() starts the event loop: the program waits for clicks and key presses. Code after it doesn't run until the window closes.

Adding a button

A button runs a function when clicked. Pass the function name without parentheses:

import tkinter as tk

clicks = 0

def on_click():
    global clicks
    clicks += 1
    label.config(text=f"Clicked {clicks} times")   # change the label's text

window = tk.Tk()
window.title("Click Counter")
label = tk.Label(window, text="Clicked 0 times", font=("Arial", 14))
label.pack(pady=10)
tk.Button(window, text="Click me!", command=on_click).pack(pady=10)
window.mainloop()

command=on_click() (with parentheses) runs the function once at start-up instead of on each click. Use command=on_click.
