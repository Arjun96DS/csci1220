3.2 Return Values and Lambda Functions

Read: Python Unlocked, Chapter 5, "Return Values" and "Lambda Functions"

Returning a value

print() only shows a value. return hands the value back so the rest of your program can use it:

def calculate_area(length, width):
    area = length * width
    return area

result = calculate_area(12, 8)
print(f"The area is: {result} square meters")

A very common bug: printing inside a function when you meant to return. If a function only prints, result = my_function() stores None.

Functions that return different kinds of values

def get_full_name(first, last):
    return first + " " + last

def is_adult(age):
    return age >= 18          # returns True or False

def calculate_grade(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    else:
        return "F"

print(get_full_name("Arjun", "Sunke"))
print(is_adult(30))
print(calculate_grade(85))

Returning more than one value

def get_min_max(numbers):
    return min(numbers), max(numbers)

lowest, highest = get_min_max([78, 92, 45, 88, 61, 99, 53])
print(f"Lowest: {lowest}, Highest: {highest}")

A real-world example: final price with discount and tax

def calculate_final_price(original_price, discount_percent, tax_percent):
    discount_amount = original_price * (discount_percent / 100)
    discounted_price = original_price - discount_amount
    tax_amount = discounted_price * (tax_percent / 100)
    return discounted_price + tax_amount

print(f"Laptop: ${calculate_final_price(1000, 10, 7.875):.2f}")
print(f"Headphones: ${calculate_final_price(199, 0, 7.875):.2f}")

Lambda functions (short, one-line functions)

A lambda is a tiny unnamed function. It's most useful for telling sorted() how to sort:

square = lambda x: x * x
print(square(5))

students = [{"name": "Priya", "score": 88}, {"name": "Rahul", "score": 72}, {"name": "Sneha", "score": 95}]
ranked = sorted(students, key=lambda s: s["score"], reverse=True)
for s in ranked:
    print(f"{s['name']}: {s['score']}")

Don't worry if the {"name": ...} syntax looks new. Those are dictionaries, which you'll learn in Module 6.
