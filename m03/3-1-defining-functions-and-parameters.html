3.1 Defining Functions and Parameters

Read: Python Unlocked, Chapter 5, "Defining Functions" through "Keyword Arguments"

A function is a named block of code you can run whenever you need it. Functions let you write something once and reuse it, and they break big programs into small, understandable pieces.

You've already used built-in functions like print(), input(), and len(). Now you'll write your own.

Defining and calling a function

def greet():
    print("Hello! Welcome to Python.")
    print("We are glad you are here.")

greet()   # call it once
greet()   # call it again
  • def starts the definition, followed by the name, parentheses, and a colon.
  • The indented lines are the function's body.
  • Defining a function doesn't run it. Calling it (greet()) does.

Parameters: giving a function information

def introduce(name, age, city):
    print(f"Hi, my name is {name}. I am {age} years old and I live in {city}.")

introduce("Arjun", 30, "Albuquerque")
introduce("Maria", 25, "Santa Fe")

name, age, and city are parameters (placeholders). The values you pass in are arguments.

Default values

A parameter can have a default that's used when no argument is given:

def greet_person(name, language="English"):
    if language == "English":
        print(f"Hello {name}!")
    elif language == "Spanish":
        print(f"Hola {name}!")
    elif language == "Hindi":
        print(f"Namaste {name}!")

greet_person("Arjun")              # uses the default: English
greet_person("Carlos", "Spanish")

Keyword arguments

You can name the arguments when calling, so the order doesn't matter. This makes calls easier to read:

def introduce(name, age, city):
    print(f"Hi, my name is {name}. I am {age} years old and I live in {city}.")

introduce(age=28, city="Las Cruces", name="Vikram")
