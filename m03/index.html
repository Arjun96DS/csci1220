Module 3 – Functions and Scope

As programs grow, you need a way to organize them. Functions let you package code into reusable, named pieces. In this module you'll write your own functions, pass information into them, get results back, and learn where variables "live".

Reading: Python Unlocked, Chapter 5

By the end of this module, you will be able to:

  • 3.1 Define and call functions
  • 3.2 Use parameters, default values, and keyword arguments
  • 3.3 Return one or more values from a function
  • 3.4 Write simple lambda functions
  • 3.5 Explain local and global scope and the LEGB rule
