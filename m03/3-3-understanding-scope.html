3.3 Understanding Scope

Read: Python Unlocked, Chapter 5, "Understanding Scope"

Scope is where a variable can be seen and used.

Local scope

A variable created inside a function only exists inside that function:

def calculate_bonus(salary):
    bonus = salary * 0.10
    print(f"Inside function - bonus is: {bonus}")

calculate_bonus(5000)
# print(bonus)   # NameError: bonus doesn't exist out here

That's a good thing: functions can't accidentally overwrite each other's variables.

Global scope

A variable created outside all functions can be read inside a function:

company_name = "Sandia Tech Solutions"

def display_company():
    print(f"Welcome to {company_name}!")

display_company()

Changing a global variable

To change a global variable inside a function, you must say global:

counter = 0

def increment():
    global counter
    counter += 1

increment()
increment()
print(counter)   # 2

Best practice: avoid global. Pass values in as parameters and return results instead. Your code is easier to test and debug that way.

The LEGB rule

When Python looks up a name, it searches in this order: Local → Enclosing → Global → Built-in. The first match wins:

name = "Global Arjun"

def show_name():
    name = "Local Arjun"
    print(f"Inside function: {name}")

show_name()
print(f"Outside function: {name}")
