8.2 Multiple Exceptions, else and finally

Read: Python Unlocked, Chapter 7, "Catching Multiple Exceptions" through "Handling File Errors"

Catching different exceptions differently

def divide_numbers(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        print("Error: Cannot divide by zero!")
    except TypeError:
        print("Error: Both values must be numbers!")
    return None

print(divide_numbers(10, 2))
print(divide_numbers(10, 0))
print(divide_numbers(10, "five"))

else and finally

  • else runs only if no exception happened.
  • finally always runs. It's used for cleanup, like closing connections or printing "done".
try:
    number = int(input("Enter a number: "))
    result = 100 / number
except ValueError:
    print("That is not a valid number!")
except ZeroDivisionError:
    print("Cannot divide by zero!")
else:
    print(f"Result: {result}")
finally:
    print("Program finished. This always runs.")

Getting the error message with as

try:
    file = open("nonexistent_file.txt", "r")
except FileNotFoundError as error:
    print(f"File error occurred: {error}")

Handling file errors

filename = input("Enter the filename to read: ")
try:
    with open(filename, "r") as file:
        print(file.read())
except FileNotFoundError:
    print(f"Sorry, the file '{filename}' does not exist.")
except PermissionError:
    print(f"Sorry, you do not have permission to read '{filename}'.")
