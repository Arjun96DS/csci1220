Module 8 – Handling Errors and Exceptions

Real users type the wrong thing, files go missing, and data arrives messy. Professional programs don't crash; they handle problems gracefully. In this module you'll read error messages, catch exceptions, and raise your own to reject bad data.

Reading: Python Unlocked, Chapter 7 (try and except through Raising Your Own Exceptions)

By the end of this module, you will be able to:

  • 8.1 Explain what an exception is and read a traceback
  • 8.2 Catch exceptions with try and except
  • 8.3 Catch several different exceptions
  • 8.4 Use else and finally
  • 8.5 Raise your own exceptions to reject invalid data
