8.1 What Is an Exception

Read: Python Unlocked, Chapter 7, "try and except"

An exception is an error that happens while your program is running: the user types "ten" instead of 10, a file is missing, or you divide by zero. If you don't handle it, your program crashes.

Reading an error message (traceback)

age = int("ten")
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    age = int("ten")
ValueError: invalid literal for int() with base 10: 'ten'

Read tracebacks from the bottom up: the last line tells you the exception type (ValueError) and what went wrong. The line above it shows exactly which line of code caused it.

Handling an exception with try / except

Put risky code in try. If an exception happens, Python jumps to except instead of crashing:

try:
    result = 10 / 0
except ZeroDivisionError:
    print("Error: You cannot divide by zero!")
print("The program keeps running.")

Always name the exception you expect (except ValueError:). A bare except: catches everything, including typos in your own code, which hides bugs.

The most useful pattern: validating input

while True:
    try:
        quantity = int(input("How many tickets? "))
        break                        # only reached if int() worked
    except ValueError:
        print("Please enter a whole number, like 3.")
print(f"Booking {quantity} tickets.")
