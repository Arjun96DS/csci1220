4.3 Tuples

Read: Python Unlocked, Chapter 6, "Tuples"

A tuple is like a list, but it can't be changed after it's created (it's immutable). Tuples use parentheses:

coordinates = (35.0844, -106.6504)   # Albuquerque latitude, longitude
rgb_color = (255, 128, 0)
person = ("Arjun", 30, "Albuquerque")
print(person[0])     # Arjun
print(person[-1])    # Albuquerque
print(rgb_color[1:]) # (128, 0)

Trying to change a tuple, like person[1] = 31, gives a TypeError. That's the point: tuples protect data that shouldn't change.

A tuple with one item

You need a trailing comma, otherwise Python treats the parentheses as normal math brackets:

single = ("Python",)
not_a_tuple = ("Python")
print(type(single), type(not_a_tuple))

Tuple unpacking

You can pull the values out into separate variables in one line:

person = ("Arjun", 30, "Albuquerque")
name, age, city = person
print(f"{name} is {age} and lives in {city}")

You've already seen this: when a function returns two values (return min(x), max(x)), it's really returning a tuple.

Converting between lists and tuples

days = ("Mon", "Tue", "Wed")
day_list = list(days)       # now changeable
day_list.append("Thu")
days = tuple(day_list)      # lock it again
print(days)

When to use a tuple instead of a list

  • The data is a fixed record that shouldn't change: coordinates, a date, RGB colors, a database row.
  • You're returning several values from a function.
  • Use a list when the collection will grow, shrink, or change.
