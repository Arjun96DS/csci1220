4.2 List Methods and Looping Through Lists

Read: Python Unlocked, Chapter 6, "Useful List Methods", "Looping Through Lists", "Checking Membership"

Useful built-in functions and methods

numbers = [5, 2, 8, 1, 9, 3, 7, 4, 6]
print(len(numbers))       # 9 items
print(sum(numbers))       # 45
print(min(numbers), max(numbers))   # 1 9
print(sum(numbers) / len(numbers))  # average: 5.0
print(numbers.count(5))   # how many 5s: 1
print(numbers.index(9))   # position of 9: 4

Sorting

scores = [72, 95, 88, 61, 79]
print(sorted(scores))                 # new sorted list; original unchanged
print(sorted(scores, reverse=True))   # highest first
scores.sort()                         # sorts the list itself
print(scores)
top_three = sorted(scores, reverse=True)[:3]
print(f"Top 3: {top_three}")

sorted(list) returns a new list. list.sort() changes the original list and returns None.

Looping through lists

students = ["Priya", "Rahul", "Sneha"]
for student in students:
    print(f"Hello {student}!")

# enumerate() gives you the position AND the item
for index, student in enumerate(students, start=1):
    print(f"{index}. {student}")

# zip() walks through two lists side by side
scores = [88, 72, 95]
for name, score in zip(students, scores):
    print(f"{name} scored {score}")

Building a new list in a loop

temperatures = [68, 75, 91, 88, 102, 79, 95]
hot_days = []
for t in temperatures:
    if t >= 90:
        hot_days.append(t)
print(f"Hot days: {hot_days} ({len(hot_days)} of {len(temperatures)})")

Checking membership with in

allowed_users = ["mgarcia", "jsmith", "akumar"]
user = "jsmith"
if user in allowed_users:
    print("Access granted")
print("bwayne" not in allowed_users)   # True
