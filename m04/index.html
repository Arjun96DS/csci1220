Module 4 – Lists and Tuples

Real programs work with collections of data: a list of customers, a series of sensor readings, a shopping cart. In this module you'll store many values in lists and tuples, pick out the ones you need, and process them with loops.

Reading: Python Unlocked, Chapter 6 (Lists and Tuples sections)

By the end of this module, you will be able to:

  • 4.1 Create lists and access items with indexing
  • 4.2 Get parts of a list with slicing
  • 4.3 Add, change, and remove list items
  • 4.4 Use common list functions and methods (len, sum, min, max, sort)
  • 4.5 Loop through lists using enumerate() and zip()
  • 4.6 Create tuples, unpack them, and explain when to use a tuple instead of a list
