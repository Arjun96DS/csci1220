4.1 Lists – Indexing, Slicing and Changing Items

Read: Python Unlocked, Chapter 6, "Lists" (Indexing, Slicing, Modifying Lists)

A list stores many values in one variable, in order. Use square brackets and separate items with commas:

fruits = ["apple", "banana", "mango", "orange", "grapes"]
numbers = [10, 25, 3, 78, 42, 15]
mixed = ["Arjun", 30, True, 3.14]
print(fruits)

Indexing: getting one item

Each item has a position number called an index. Counting starts at 0. Negative indexes count from the end:

fruits = ["apple", "banana", "mango", "orange", "grapes"]
print(fruits[0])    # apple   (first)
print(fruits[4])    # grapes
print(fruits[-1])   # grapes  (last)
print(fruits[-2])   # orange  (second to last)
Index01234
Itemapplebananamangoorangegrapes
Negative index-5-4-3-2-1

fruits[5] gives an IndexError: a 5-item list only goes up to index 4.

Slicing: getting several items

list[start:stop] gives the items from start up to, but not including, stop:

fruits = ["apple", "banana", "mango", "orange", "grapes"]
print(fruits[1:4])   # ['banana', 'mango', 'orange']
print(fruits[:3])    # first three
print(fruits[2:])    # from index 2 to the end
print(fruits[-3:])   # last three
print(fruits[::-1])  # reversed copy

Changing, adding, and removing items

Lists are mutable: you can change them after creating them.

cart = ["laptop", "mouse", "keyboard"]
cart[1] = "wireless mouse"      # change an item
cart.append("monitor")          # add to the end
cart.insert(0, "laptop bag")    # add at a position
cart.extend(["usb hub", "webcam"])  # add several
print(cart)

cart.remove("keyboard")         # remove by value
last = cart.pop()               # remove and return the last item
first = cart.pop(0)             # remove and return item at index 0
print(f"Removed {last} and {first}")
print(cart)
