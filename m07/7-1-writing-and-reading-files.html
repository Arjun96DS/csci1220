7.1 Writing and Reading Files

Read: Python Unlocked, Chapter 7, "Reading and Writing Files"

Every variable you've used so far disappears when your program ends. Files let your data survive: save it today, load it tomorrow. This is called persistence.

File modes

ModeMeaningIf the file doesn't existIf it does exist
"r"readerrorreads it
"w"writecreates iterases it and starts fresh
"a"appendcreates itadds to the end

Writing a file

Always use with. It closes the file for you automatically, even if something goes wrong:

with open("students.txt", "w") as file:
    file.write("Priya Sharma - Score: 88\n")
    file.write("Rahul Verma - Score: 72\n")
    file.write("Sneha Patel - Score: 95\n")
print("File written successfully!")

write() does not add a new line for you. End each line with \n (the newline character).

Reading the whole file

with open("students.txt", "r") as file:
    content = file.read()
print(content)

Reading line by line

Best for large files. strip() removes the \n at the end of each line:

with open("students.txt", "r") as file:
    for line in file:
        print(line.strip())

Reading all lines into a list

with open("students.txt", "r") as file:
    lines = file.readlines()
print(f"Total records: {len(lines)}")
print(f"First record: {lines[0].strip()}")
print(f"Last record: {lines[-1].strip()}")
