7.2 Appending and Working with CSV Data

Read: Python Unlocked, Chapter 7, "Appending to a File" and "A Practical File Example"

Appending

with open("students.txt", "a") as file:
    file.write("Karan Mehta - Score: 91\n")
print("New record added!")

Making sure a file exists

Reading a file that doesn't exist crashes your program. A simple trick: open it in append mode first, which creates an empty file if needed and changes nothing if it already exists:

open("expenses.csv", "a").close()   # creates the file only if it's missing
with open("expenses.csv", "r") as file:
    print(f"{len(file.readlines())} lines in the file")

CSV: the most common data file format

CSV (comma-separated values) stores one record per line, with fields separated by commas. Excel and Google Sheets can open it, and almost every system can export it.

students_data = [("Priya Sharma", 88), ("Rahul Verma", 72), ("Sneha Patel", 95), ("Vikram Singh", 81)]

# Save as CSV
with open("scores.csv", "w") as file:
    for name, score in students_data:
        file.write(f"{name},{score}\n")

# Read it back and calculate the average
total = 0
count = 0
with open("scores.csv", "r") as file:
    for line in file:
        name, score = line.strip().split(",")
        total += int(score)
        count += 1
        print(f"{name}: {score}")
print(f"Class average: {total / count:.2f}")

Everything you read from a file is a string. Convert numbers with int() or float() before doing math, just like with input().

Going further: the csv module

Real CSV files can contain commas inside a field (like "Albuquerque, NM"). Python's built-in csv module handles that correctly:

import csv

with open("contacts.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["name", "city"])
    writer.writerow(["Maria Garcia", "Albuquerque, NM"])

with open("contacts.csv", "r", newline="") as file:
    for row in csv.reader(file):
        print(row)
