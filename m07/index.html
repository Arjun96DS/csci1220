Module 7 – Working with Files

Until now, all your data disappeared when your program ended. In this module you'll save data to files and load it back, so your programs can remember things. You'll also work with CSV, one of the most common data formats in the world.

Reading: Python Unlocked, Chapter 7 (Reading and Writing Files)

By the end of this module, you will be able to:

  • 7.1 Explain the read, write, and append file modes
  • 7.2 Write text to a file using with open()
  • 7.3 Read a file all at once, line by line, or into a list
  • 7.4 Append new data to an existing file
  • 7.5 Save and load CSV data and convert it to the right types
