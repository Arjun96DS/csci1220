6.2 Sets

Read: Python Unlocked, Chapter 6, "Sets"

A set is a collection of unique items with no duplicates and no particular order. Sets are perfect for removing duplicates and comparing groups.

fruits = {"apple", "banana", "mango", "apple", "banana"}
print(fruits)        # duplicates are removed automatically
print(len(fruits))   # 3

Removing duplicates from a list

visitors = ["10.0.4.21", "10.0.4.57", "10.0.4.21", "10.0.7.12", "10.0.4.57"]
unique_visitors = set(visitors)
print(f"{len(visitors)} visits from {len(unique_visitors)} unique IP addresses")

Adding and removing

skills = {"Python", "SQL"}
skills.add("Linux")
skills.add("Python")          # already there, so nothing changes
skills.discard("Excel")       # no error even if it isn't there
print(skills)

Set operations: comparing groups

python_students = {"Priya", "Rahul", "Sneha", "Vikram"}
cloud_students = {"Rahul", "Ananya", "Sneha", "Meera"}

print(python_students | cloud_students)   # union: in either class
print(python_students & cloud_students)   # intersection: in both classes
print(python_students - cloud_students)   # difference: only in Python
print(python_students ^ cloud_students)   # in one class but not both
OperatorNameReal-world question it answers
|UnionWho is in either group?
&IntersectionWho is in both groups?
-DifferenceWho is in the first group but not the second?
^Symmetric differenceWho is in exactly one group?

{} creates an empty dictionary, not a set. For an empty set, use set().
