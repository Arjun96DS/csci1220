Module 6 – Dictionaries, Sets and Comprehensions

Lists are great for ordered data, but much real-world data is about looking things up: a price for a product, a record for a student ID. In this module you'll use dictionaries for lookups, sets for unique values and comparisons, and comprehensions to build collections in one line.

Reading: Python Unlocked, Chapter 6 (Dictionaries, Sets, and Comprehensions sections)

By the end of this module, you will be able to:

  • 6.1 Create dictionaries and access, add, update, and remove key-value pairs
  • 6.2 Loop through dictionaries and count items with get()
  • 6.3 Work with nested dictionaries
  • 6.4 Use sets to remove duplicates and compare groups (union, intersection, difference)
  • 6.5 Build lists and dictionaries with comprehensions
