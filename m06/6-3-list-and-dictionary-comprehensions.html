6.3 List and Dictionary Comprehensions

Read: Python Unlocked, Chapter 6, "List Comprehensions" and "Dictionary Comprehensions"

A comprehension builds a new list (or dictionary) in one readable line. It's a shortcut for the "loop and append" pattern you already know.

From loop to comprehension

# The long way
squares = []
for n in range(1, 11):
    squares.append(n ** 2)

# The comprehension way: same result
squares = [n ** 2 for n in range(1, 11)]
print(squares)

Read it as: "n squared, for each n in 1 to 10."

Filtering with if

scores = [45, 78, 92, 31, 65, 88, 22, 71]
passing = [s for s in scores if s >= 70]
print(passing)

Transforming with if/else

scores = [45, 78, 92, 31]
results = ["Pass" if s >= 70 else "Fail" for s in scores]
print(results)

A real-world use: cleaning data

raw_names = [" arjun ", "PRIYA", "rahul sharma", " SNEHA "]
clean_names = [name.strip().title() for name in raw_names]
print(clean_names)

Dictionary comprehensions

students = ["Priya", "Rahul", "Sneha"]
scores = [88, 72, 95]
score_dict = {name: score for name, score in zip(students, scores)}
print(score_dict)

honor_roll = {name: score for name, score in score_dict.items() if score >= 85}
print(honor_roll)

Use a comprehension when it fits comfortably on one line. If you need several steps or nested ifs, a regular loop is clearer.
