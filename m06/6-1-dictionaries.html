6.1 Dictionaries

Read: Python Unlocked, Chapter 6, "Dictionaries"

A dictionary stores data as key: value pairs. Instead of looking things up by position (like a list), you look them up by a meaningful key, just like looking up a word in a real dictionary.

student = {
    "name": "Priya Sharma",
    "age": 22,
    "course": "Computer Science",
    "gpa": 3.85,
}
print(student["name"])     # Priya Sharma
print(student["gpa"])      # 3.85

Safe lookups with get()

student["phone"] crashes with a KeyError if the key doesn't exist. get() doesn't:

student = {"name": "Priya Sharma", "age": 22}
print(student.get("phone"))                    # None
print(student.get("phone", "Not provided"))    # Not provided

Adding, updating, and removing

student = {"name": "Priya Sharma", "age": 22, "is_active": True}
student["email"] = "priya@example.com"   # add a new key
student["age"] = 23                      # update an existing key
student.pop("is_active")                 # remove a key
del student["email"]                     # another way to remove
print(student)
print("age" in student)                  # check whether a key exists: True

Looping through a dictionary

prices = {"coffee": 3.50, "bagel": 2.25, "smoothie": 6.75}
for item, price in prices.items():
    print(f"{item}: ${price:.2f}")
print(list(prices.keys()))
print(sum(prices.values()))

Counting with a dictionary

A classic pattern. get(key, 0) starts each count at zero:

votes = ["tacos", "pizza", "tacos", "sushi", "tacos", "pizza"]
counts = {}
for vote in votes:
    counts[vote] = counts.get(vote, 0) + 1
print(counts)    # {'tacos': 3, 'pizza': 2, 'sushi': 1}

Nested dictionaries

A value can itself be a dictionary. This is how real data (like JSON from a web API) is usually shaped:

classroom = {
    "S001": {"name": "Priya", "score": 88},
    "S002": {"name": "Rahul", "score": 72},
    "S003": {"name": "Sneha", "score": 95},
}
for student_id, info in classroom.items():
    print(f"{student_id} - {info['name']}: {info['score']}")
